# Changelog

## 0.2 (12 Oct 2026)
- Journal: weight tracker (kg / lb, trend chart over 30 or 90 days, change since the last entry).
- Journal: calorie tracker (meals, daily goal, progress bar, 14-day chart, 7-day average).
- Weight and calories are included in the journal entries list, the JSON export / import and the journal streak.
- Requirements and tests extended to 115 checks (JRN-12 to JRN-19).
- Repository: Pages workflow now publishes only `index.html`; added `.gitignore` and this changelog.

## 0.1 (9-11 Oct 2026)
- Habit tracker, planner with goals, budget tracker (payment plans, selected-day repeats, live exchange rates), journal with hourly mood and emotion wheel.
- Pomodoro timer and clock on every page, JSON auto-save with export / import, offline use (font embedded).
- Footer disclaimer and version number; MIT licence.
- Requirements list and Playwright validator.
